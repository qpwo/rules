FULL-PARAMETER FINE-TUNING OF GEMMA 4 26B MoE ON AGENT TRACES
WITHOUT CATASTROPHIC FORGETTING - RESEARCH SUMMARY

USE CASE: 5000 high-quality bash agent traces, Gemma 4 26B MoE (26B total, 4B active)
GOAL: Full precision full weight fine-tuning without breaking the model

METHODS APPROACHING 10x IMPROVEMENT IN FORGETTING PREVENTION:
================================================================================

1. SELECTIVE COMPONENT TUNING (2510.08564, UIUC/Google/CMU)
   6-38x less forgetting than full FT, BETTER learning than full FT
   METHOD: Freeze W_down (down projection), update only Gate&Up
   MECHANISM: W_down = unconstrained write-back causing output distribution drift
   RESULTS: Full FT: learn +29.9, forget -27.4 | MLP(Gate&Up): learn +35.1, forget -2.1
   No replay, no extra params, no per-stage tuning
   For MoE: update expert Gate&Up, freeze expert W_down

2. SDFT - SELF-DISTILLATION FINE-TUNING (2601.19897, MIT)
   8.85x better IFeval preservation (74.3->72.3 vs SFT 74.3->35.3)
   METHOD: KL divergence between model's own outputs and fine-tuned outputs
   Full-parameter FT (not LoRA/PEFT)
   Tested on Qwen2.5-7B (dense, not MoE)

3. DES-MoE (2509.16882, EMNLP 2025, HKUST)
   89% less forgetting, preserves 98% capabilities, 68% faster
   MoE-SPECIFIC! Three innovations:
   - Adaptive Lightweight Router (ALR): trainable MLP + distillation KL loss
   - Domain-Guided Expert Specialization (DGES): track expert-domain relevance, mask gradients
   - Progressive schedule: Warm-Up (all trainable) -> Stabilization (freeze backbone) -> Consolidation (freeze all except domain experts)
   Tested on DeepSeek-V2-Lite (66 experts, 8 active)

4. SPARSE MEMORY FINETUNING (2510.15103, FAIR/Meta)
   89% -> 11% forgetting (8x improvement), same learning as full FT
   METHOD: Memory layers with TF-IDF ranking, update only 25-500 indices per batch
   SGD not AdamW (AdamW bad with sparsity)
   Memory layers = "MoE with large number of small experts"
   Tested on fact learning, not agent traces

================================================================================
MoE-SPECIFIC INSIGHTS (Mechanistic Analysis, 2601.18699):
================================================================================
- MoE and GQA AMPLIFY catastrophic forgetting
- MoE routing gates are HIGHLY sensitive to domain shifts
- Freezing MoE gates DOESN'T WORK - "severely limits plastic capacity"
- Optimal: soft L2 penalty on gate logits during task transition
- Mid-layer MoE/MLP blocks have HIGHEST representation drift
- W_down matrices exhibit highest parameter drift rates
- LRCP: SVD projection on vulnerable circuits, 94.2% forgetting mitigation
- Optimal SVD rank ratio: 0.20

OTHER RELEVANT METHODS:
================================================================================
- RevFFN (2512.20920): Full-param MoE FT with reversible blocks, 3.2x less VRAM
  NOTE: Freezes MoE gates, but Mechanistic Analysis says this doesn't work!
- Sculpting Subspaces (2504.07097, ICLR 2026): SVD-based full-param FT, no extra params
- CoSo (2505.11816, NeurIPS 2025): Gradient subspace optimization, full-param FT
- HFT (2404.18466, ACL 2025): Freeze half, train half, outperforms full FT
- MoLF (2605.07111, CMU): Mixture of LoRA and full FT, tested on Gemma-3-1B
  For skills, LoRA's regularization helps. For knowledge, full FT needed.
- CSO: Critical step optimization for agent traces, 37% over SFT
- RL's Razor (2509.04259): RL forgets less than SFT, KL divergence controls forgetting
- SFT and RL are nearly orthogonal: SFT can forget, RL can recover

RECOMMENDED COMBINATION FOR GEMMA 4 26B MoE ON BASH AGENT TRACES:
================================================================================

1. DES-MoE framework: adaptive router + expert isolation + progressive freezing
   - Identify which experts are most relevant to bash agent behavior
   - Only update those experts, freeze the rest
   - Three-phase: Warm-Up -> Stabilization -> Consolidation

2. Selective Component Tuning: within selected experts, freeze W_down
   - Update only Gate&Up projections
   - Prevents output distribution drift (the main cause of forgetting)

3. SDFT: add self-distillation KL loss
   - KL divergence between original model outputs and fine-tuned outputs
   - Preserves IFeval (instruction following = agentic capability)

4. Soft L2 on MoE gate logits (NOT freezing)
   - Prevents routing collapse while allowing adaptation
   - From Mechanistic Analysis paper

5. CSO: weight critical steps in agent traces
   - Identify pivotal turns in bash agent traces
   - Weight those steps more heavily in training

6. Memory efficiency (optional): RevFFN or GaLore or HiFT
   - RevFFN: reversible blocks, 3.2x less VRAM (but don't freeze gates!)
   - GaLore: gradient low-rank projection
   - HiFT: hierarchical full-param FT

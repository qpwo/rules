================================================================================
USE CASE: Teach Gemma 4 26B MoE to navigate 3000 county health inspection websites,
extract business docs, health inspections, reviews, verify real/non-fake/from-source.
Score: 1pt each for 3 things if real, not fake, from source not aggregator.

THE 10x METHODS (confirmed by research):
================================================================================

1. WEASEL (2605.20291) - 9.7-12.5x TRAINING SPEEDUP + BETTER OOD GENERALIZATION
   "Trajectory selection for offline web agent training that balances unary importance
   with pairwise diversity, improving out-of-domain generalization while delivering
   9.7-12.5x training speedups."
   KEY: Mitigates overfitting to website-specific artifacts.
   PERFECT for user: train on some county sites, generalize to all 3000 with 10x speedup.
   Code: https://github.com/yeonjooooni/WEASEL (or via paper)

2. Web-Shepherd (2505.15277, NeurIPS 2025 Spotlight) - 10x CHEAPER + 10.9 POINTS BETTER
   "First process reward model (PRM) for web navigation. 10.9 points better performance,
   in 10x less cost compared to using GPT-4o-mini as the verifier."
   KEY: Checklist-based PRM, handles text AND visual inputs.
   40K step-level dataset (WebPRM Collection).
   GitHub: kyle8581/Web-Shepherd
   PERFECT for user: step-level reward for multi-step county website navigation.

3. Unsloth - 12x FASTER MoE TRAINING, 60% LESS VRAM
   "Unsloth trains Gemma 4 ~1.5x faster with ~60% less VRAM than FA2 setups."
   Supports ALL vision, text, audio and RL fine-tuning for Gemma 4.
   GRPOTrainer with agent GRPO support uses fast_inference patching.
   KEY: User can do vision GRPO for Gemma 4 26B MoE directly.

4. VeriEnv (2603.10505, ICML 2026) - CLONE REAL WEBSITES FOR TRAINING
   "Automatically cloning real-world websites into fully executable synthetic environments
   with deterministic, verifiable rewards."
   $3.60 per environment, 83.5 minutes average.
   Agents "generalize to unseen websites, achieve site-specific mastery."
   GitHub: kyle8581/VeriEnv (SAME GROUP as Web-Shepherd!)
   PERFECT for user: clone 3000 county health inspection websites for training.
   Total cost: 3000 x $3.60 = $10,800.

5. RLVR - VERIFIABLE REWARDS (much simpler than RLHF)
   User's reward IS verifiable: did agent find real doc from official source?
   Binary verifiable reward: 1 if found real doc from source, 0 otherwise.
   "GRPO eliminates value network entirely, halving memory overhead."

6. RFT NATURALLY MITIGATES FORGETTING
   "Reinforcement Fine-Tuning naturally mitigates catastrophic forgetting that plagues SFT."
   MIT study: "RL reduces catastrophic forgetting versus SFT, using KL divergence."
   BUT "RL Forgets!" (2607.04364): "Preventing forgetting requires explicitly constraining
   policy behavior on prior tasks, as current-task KL regularization is insufficient."
   SOLUTION: Add KL divergence term to GRPO + SDFT (self-distillation).

HYPERPARAMETERS:
================================================================================
  - Learning rate: 2e-6 for RL (lower than SFT, MoE routing is fragile)
  - Batch size: 32-128 with gradient accumulation (small batch = common mistake!)
  - Epochs: 1-3 (more risks overfitting)
  - GRPO: no value network needed (halves memory)
  - KL coefficient: 0.02-0.05 for MoE (higher than dense to prevent divergence)
  - Clip range: 0.1-0.2 (tighter for MoE stability, relax once rewards climb)
  - Temperature: 1.0, top_p: 0.95, top_k: 64 (Gemma 4 recommended)
  - KL divergence: add to GRPO loss for forgetting prevention
  - VRAM: >40GB for LoRA, user has 8x B200 (not an issue)
  - Vision: Gemma 4 handles images natively, no separate vision encoder needed
  - Vision formatting: Image content goes BEFORE text in prompt
  - Reward: binary verifiable (1 = found real doc from source, 0 = otherwise)
  - Process reward: Web-Shepherd for step-level feedback
  - Invalid actions: penalize with reward of -0.1
  - Action masking: ONLY agent-generated tokens contribute to policy gradient
  - CRITICAL: Without proper action/advantage masking, agent RL collapses
  - MoE stability: monitor routing stability, use load balancing loss/z-loss
  - MoE routing: RL updates all params jointly (experts+gate+routing biases)
  - Expert collapse: all tokens to same expert = bottleneck. Use load balancing.
  - DeepSeek trick: loss-free balancing via per-expert bias terms
  - Warm start: SFT warm-start recommended before RL (OpenWebRL)
  - Data: OpenWebRL achieved 67% with only 400 trajectories. User has 5000 = 12.5x more.

================================================================================
REWARD DESIGN (CRITICAL):
================================================================================
  1. Binary outcome (RLVR): 1 = found real doc from source, 0 = otherwise
     - "Verifiable Rewards are simple functions: 1 for correct, 0 for incorrect"
     - Mitigates reward hacking (hard to cheat a verifier)
     - WARNING: "Gradient Starvation in Binary-Reward GRPO" - pure binary can fail
  2. Shaped rewards (Mind2Web Autopsy): partial credit based on failure mode
     - "Replace binary pass/fail with verifiable reward that gives partial credit"
     - Helps when binary reward is too sparse (most trajectories get 0)
  3. Step-level (Web-Shepherd): 10x cheaper than GPT-4o-mini
     - Checklist-based PRM, handles text AND visual inputs
     - Provides dense supervision and credit assignment
  4. Evidence-aware (EVE-Agent): rewards explicit planning + evidence verification
     - "evidence-aware reward shaping accelerates evidence acquisition"
  5. Invalid action penalty: -0.1 for invalid actions (GiGPO, NeurIPS 2025)
  6. User's specific reward function:
     - 1pt for business incorporation doc (real, from source, not aggregator)
     - 1pt for health inspection report (real, from source, not aggregator)
     - 1pt for reviews (real, from source, not aggregator)
     - Source = official .gov or official review platform, not aggregator
     - Verification: URL/domain check + document analysis (letterhead, seals)

   - KL divergence term for forgetting prevention
   - WebRL self-evolving curriculum (easy -> hard)

   - Score: 1pt each for business docs, health inspection, reviews
   - Must be real, not fake, from source not aggregator
   - Monitor IFeval for forgetting

7. If IFeval drops: add SDFT + GeRe
8. If OOD performance is low: add more diverse training sites
9. Scale to 500+ cloned sites if needed
